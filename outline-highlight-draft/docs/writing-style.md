# 标绿稿写作风格

本文规定标绿稿的语言、讲解和事实表达。生成、重写或润色正文前必须读取。

## 对象与语气

- 面向 9-12 岁学生。
- 像真实讲解者口头讲给学生听，亲切、准确、不过度幼稚。
- 使用“我们”“你”拉近距离，但不要变成教学口号。
- 正文要能直接朗读，不像教案说明、制作说明或知识点清单。

## 知识组织

- 关键问题之间的顺序跟随大纲框架或内容简案。
- **关键问题内部的知识点顺序自己定。**框架里 bullets 的排列是教研梳理知识时的记录顺序，不一定是最好的口播顺序。哪个顺序读起来更顺、因果链更完整，就按哪个写。
- 每个部分内部要有清楚结构，常用路径包括：
  - 整体 → 局部
  - 现象 → 解释 → 证据
  - 是什么 → 为什么 → 有什么影响
  - 先回答核心判断 → 再补例子、证据或类比
- 上面这些路径优先于框架 bullets 的原始排列。如果框架的排列和它们冲突，按路径重排。
- 同一关键问题下不要把位置、结构、功能、证据来回跳着讲；先搭出结构，再填细节。

### 主动找更好的讲解顺序

写每个关键问题之前，先把框架给的 bullets 列出来，判断这个顺序读出来顺不顺。不顺就重排，不要因为框架这么排就照着写。常见的重排场景：

- **结论提前**：框架把结论放在最后一条，但口播时先给结论、再讲原因更好懂。
- **合并同类**：框架分成三条写的其实是一件事的三个侧面，合成一段讲更连贯。
- **补因果链**：框架的 bullets 之间缺过渡，需要调整顺序才能让 A 自然引到 B。
- **拆分过载**：一条 bullet 里塞了两个独立知识点，拆开分别讲。

边界：

- **只能重排顺序、调整表述方式，不能增删知识点。**框架里有的都要讲到，框架里没有的不要自己加。
- 自由重排的范围是**同一个关键问题内部**。关键问题之间的顺序是框架定的教学逻辑，把知识点从一个关键问题搬到另一个属于结构调整，要先说明再动。
- 重排之后要在交付说明里写一句为什么这么排，方便教研复核。
- 重排知识点后，检查过渡句还成不成立——原来的“因此”“另一方面”在新顺序下常常已经不通。
- 关键问题之间要有知识内容上的自然过渡，不能只靠“接下来”“既然如此”硬切。

## 过渡句

好的过渡句通常只承担一个功能：

- 补上因果
- 指出对比
- 从现象转入解释
- 从结论转入证据
- 从局部转入影响
- 从已知内容引出未解决的问题

回顾或复习前几集内容时，不要总用“你已经知道……”开头。可以交替使用不同话术，如“上一集讲过……”“还记得……吗？”“前面提到过……”“我们了解过……”等，避免重复单调。

写完过渡句后检查：

- 它是否承接了上一段已经讲出的内容。
- 它是否真的指向下一段要讲的知识。
- 使用“但是/可是/不过”时，前后是否真的存在转折。

避免空泛转场：

- “接下来我们看看……”
- “先把镜头拉远……”
- “回到最容易误会的地方……”
- “问题来了……”
- “这个方法的妙处在于……”

这些句式不是绝对禁用，但连续出现或没有逻辑功能时要改写。

## 术语与名称

- 儿童陌生术语首次出现必须解释。
- 对陌生仪器、效应、理论、方法名，优先先描述现象、结构或用途，再给出名称。
- 示例：先讲“一个很长的摆会保持摆动方向，而地面在它下面转动”，最后再说“这个装置叫傅科摆”。
- 不要为了口语化改掉框架中的核心术语；可以在第一次出现时解释。

## 类比

- 抽象、微观、反直觉或多步骤机制可使用类比。
- 类比要来自学生熟悉经验，并与科学原理严格对应。
- 禁止嵌套类比。
- 使用“就像”“好比”“相当于”“如果把……”等标识词，避免把类比说成定义。
- 类比有明显误导风险时，用半句或一句短话处理边界；不要机械添加长免责声明。

## 科学表述风险

**科学准确性高于框架忠实度**：框架里的科学表述如果有问题，不能因为“框架就是这么写的”照抄进标绿稿。

但同样不能反过来——**发现框架的科学结论有问题时，不得在标绿稿里悄悄改掉**。框架是教研共同确认过的产物，静默修正会让两份文件的知识内容对不上，而且没人知道是谁改的、为什么改。

正确做法：

1. 在【框架检查】的「科学表述风险」里标出来，指明是哪个关键问题、哪句话。
2. 说清风险是什么：是数字不准、是因果关系倒了、还是表述过于绝对。
3. 给出建议改法，最好给出可直接替换的措辞。
4. 等用户确认后再写进标绿稿；用户不确认就按框架原样写，并在交付说明里保留这条风险提示。

以下内容出现时逐条核对，不要凭印象写：

- **具体数字**：厚度、温度、年代、速度、比例。框架给了数字就用框架的；框架没给而你想加，先确认。
- **历史案例**：时间、地点、后果规模。
- **科学家姓名和实验**：谁做的、哪一年、结论是什么。张冠李戴在科普稿里是硬伤。
- **复杂机制**：多步因果链条容易在压缩时丢掉中间环节，导致因果关系错误。
- **绝对化表述**：“所有”“一定”“不可能”“唯一”。科学结论少有这么干净的，改成“大多数”“通常”“目前认为”。
- **安全、健康、环境类内容**：涉及学生可能模仿的操作，或涉及健康结论时，从严处理。

**不得为了内容丰富，自行扩写高风险内容。**框架只写了一句话的机制，不要主动展开成三句——展开处正是错误最容易进来的地方。要展开先问。

## 数据和事实案例

- 具名科学案例、历史实验和测量故事，必须保留关键事实链：地点或对象、观察到的现象、测量或推理方法、结论数据。
- 不要为了顺口把具体方法泛化成另一种说法。
- 引用结果数字时，优先给出可理解的对照、误差意义或与现代数据的比较。
- 陌生单位要转换成学生更容易想象的表达。

## 并列概念

写并列概念前检查包含关系，避免上位/下位重复：

- 避免“海洋和水”“陆地和土壤”这类重复。
- 如果必须同时讲，改成分布、圈层或组成关系。
- 示例：不要写“地球外部不只有海洋和陆地。它还有大气、水、土壤和生物。”可改为“地球表面有海洋和陆地，外面包着大气，陆地上还有土壤和生物。”

## 句式与节奏

- 单段正文不超过 180 字。
- 全文问题句数量控制在 8 个以内。
- 问题句必须有承接作用，不能为了活泼而提问。
- 不用括号、破折号堆解释；需要补充说明时改成口语句。
- 双引号统一使用中文全角“”，不得出现半角英文直引号。
- 禁止“名词：解释”的词条格式（如“碰撞挤压：两个板块相向运动”）。正文是讲稿，不是名词解释，必须用完整的句子自然表述。
- 同一个词（如“能量”）在前后文指代不同概念时，必须用限定词区分清楚，避免指代混乱。
- 删除教学腔：“今天我们来学习”“综上所述”“如图所示”“这一集先记住”“后面会讲”。
- 删除明显 AI 腔：过密的排比、泛泛升华、连续“首先其次最后”、没有上下文依据的“更重要的是”。

## 内容边界

- 严格服务主线问题和关键问题。
- 可以补充帮助理解的例子、类比、证据和生活拓展。
- 不写框架外大段独立知识。
- 如果删掉某段后核心框架依然更清楚，那段多半是过度补充。
